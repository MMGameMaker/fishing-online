## Đã làm

- `admin/`: Vite + React 18 + TypeScript strict, ESLint, Vitest. Chạy `npm --prefix admin run dev` ở cổng 5174 (đã thêm vào `ClientOrigins` của API).
- **Đăng nhập:** Google qua Firebase JS SDK, hỏi mã TOTP khi tài khoản có MFA, rồi gọi `POST /admin/auth/login`. Access token chỉ giữ trong bộ nhớ; refresh qua cookie HttpOnly, tự refresh một lần khi gặp 401; mở lại trang thì khôi phục phiên bằng cookie.
- **Config:** bảng version (active, người publish), tạo nháp từ version bất kỳ (tạo từ version cũ là cách rollback), sửa mọi mục (level, cần, cá, Tier ghế, giá ghế, minigame, spawn, fishing, chiều dài, shop) dạng bảng hoặc ô, giữ đúng kiểu số/chuỗi. Có Lưu nháp, Kiểm tra (lỗi hiện ngay dưới mục theo đường dẫn field), Publish phải xác nhận.
- **Người chơi:** tìm theo tên/playerId; chi tiết profile, Gold, tổng ledger (xanh khi khớp số dư), cần; các tab ledger/cá/lần câu/phiên ghế phân trang; tab "Nghi vấn" cho đánh dấu đã xem/bỏ qua, không có nút ban.
- **Hồ:** 20 ghế (trạng thái, giá, hạn, cooldown), người đang online, bảng tồn cá; tự làm mới mỗi 3 giây.
- **Audit:** danh sách thao tác, xem trước/sau.
- Mục menu chỉ hiện theo quyền; mỗi trang có trạng thái đang tải, rỗng, lỗi và không có quyền.
- Server: thêm lọc `?target=` cho `GET /admin/audit` (để xem lịch sử một đợt thả).

## Lệch spec / giả định

- Hồ "realtime" bằng cách gọi lại API mỗi 3 giây, vì hub `/hubs/game` chỉ dành cho token Player.
- MFA trên giao diện chỉ hỗ trợ TOTP (ứng dụng xác thực); MFA qua SMS cần reCAPTCHA nên chưa làm.
- Chưa có danh sách nháp đang mở: tải lại trang khi đang sửa thì phải tạo nháp mới (nháp cũ vẫn nằm trong DB). Server chưa có API liệt kê nháp.
- Phiên bản thư viện ghim chính xác; ESLint 9.39.5 giống `client-v0` (npm báo bản này đã hết hỗ trợ).
