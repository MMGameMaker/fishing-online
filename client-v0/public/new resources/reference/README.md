## Tileset / tile-part

[tilesets.json](tilesets.json) liệt kê từng mảnh nền, frame ID, nhóm atlas và tile size. Dữ liệu này là tile deduplication/ghép ảnh riêng; không phải tileset Tiled. `anim/embedded-metadata-0.json` giữ vị trí ghép tile/piece gốc.

## Dùng với Phaser

- PNG và WAV/MP3: dùng loader ảnh/audio tương ứng.
- Atlas hiện có dạng TexturePacker JSON Hash: có cấu trúc phù hợp `load.atlas`; cần smoke-test rotated/trimmed frames, chưa chạy Phaser để xác nhận.
- `animations` là tên sequence → danh sách frame. Cần tạo `anims.create`, gán đúng atlas cho từng frame; tốc độ, loop và event không được bảo đảm bởi danh sách frame.
- Map JSON chứa object class, params, spawnPosition/colliders; không phải Tiled JSON. Cần factory/adapter dựng object hoặc chuyển sang Tiled.
- Dùng PNG trước; KTX/ASTC phụ thuộc renderer, GPU và cấu hình texture compression.
- GIF cần chuyển frame/atlas để phát như sprite animation; nạp ảnh thường không tự tạo animation.
- Không load toàn bộ thư viện cùng lúc; chọn atlas và audio theo scene.

Tài liệu loader: https://docs.phaser.io/phaser/concepts/loader ; texture: https://docs.phaser.io/phaser/concepts/textures .

Các object chưa ánh xạ: xem `unresolved-map-candidates.json`. Ứng viên khớp basename chỉ phục vụ tra cứu, không được tính vào phụ thuộc đã xác nhận.
